# My Portfolio

A personal portfolio website built with plain **HTML** and **CSS**. It introduces who I am, my education, my skills, some of my small achievements, and the activities I'm involved in.

This was my very first project, created as part of a Python Lab Assignment at the University of Asia Pacific.

## About the Project

The goal of this project was to build a simple, good-looking one-page website to present myself online. It is a static site, so there is nothing to install and no server is needed. You just open it in a browser.

## Features

- **Fixed navigation bar** with links that jump to each section of the page
- **Home / About** section with a short introduction and a link to download my CV
- **Education** timeline (University, HSC, SSC)
- **Skills** section with progress bars showing my skill level in each area
- **Little Achievements** section with cards (title, photo, and description)
- **Activities** section covering my YouTube channels and club membership
- **Social buttons** linking to my GitHub and LinkedIn profiles
- **Dark theme** design with custom Google Fonts and Font Awesome icons

## Built With

- **HTML5**: page structure and content
- **CSS3**: layout, colors, cards, and skill bars (Flexbox)
- **[Font Awesome 4.7](https://fontawesome.com/v4/)**: GitHub and LinkedIn icons
- **[Google Fonts](https://fonts.google.com/)**: Fira Sans, Montserrat, and Satisfy

## How to Run

1. Download or clone this repository:
   ```bash
   git clone https://github.com/21201166-Barshan/My-Portfolio.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in any modern web browser (Chrome, Firefox, Edge, Safari).

> An internet connection is needed the first time so the fonts and icons can load from the web.
